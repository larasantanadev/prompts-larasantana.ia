ECC: Everything Claude Code

Guia completo. @larasantana.ia

1. O linkRepositório oficial

github.com/affaan-m/ECC. Código aberto, licença MIT, feito por Affaan Mustafa. Não é um projeto da Anthropic. Instale só a partir desse endereço.

2. InstalarDentro do Claude Code

/plugin marketplace add https://github.com/affaan-m/ECC

Depois: /plugin install ecc@ecc

O README também mostra a instalação guiada com npx ecc-universal setup. Confira sempre o README para o comando mais atual.

3. Agentes pra ligar primeiroComece por estes

planner: planeja antes de mexer no código.

code-reviewer: revisa o seu código.

security-reviewer: procura falhas de segurança.

build-error-resolver: corrige erros de build.

AvisoLeia antes de instalar

O ECC mexe nas configurações do seu Claude Code (agentes, skills e hooks). Leia o README e teste primeiro em um projeto sem nada importante.
